Anestésicos Locais

  • MA = bloqueio de canal de Na⁺ (por dentro, forma ionizada; entra na forma não-ionizada).
  • Não pega em pus → pH ácido → fármaco ionizado → não atravessa membrana.
  • Vasoconstritor (adrenalina) → prolonga ação, ↓toxicidade, ↓sangramento. Evitar em extremidades.
  • Amida (2 "i": lidocaína, bupivacaína) = hepático, pouca alergia · Éster (procaína) = + alergia.
  • Cinética: ↑lipossol = ↑potência · ↑lig. proteica = ↑duração · ↑pKa = início + lento.
  • Toxicidade: SNC primeiro (parestesia perioral→convulsão), depois CV (bupivacaína = + cardiotóxica).

Anestésicos Gerais

Sevoflurano × Halotano: menos solúvel no sangue = indução/recuperação + rápidas (sevo). Halotano = solúvel (lento) + hepatotoxicidade + arritmia (sensibiliza a catecolamina) → por isso sevo é preferido.

Bloqueadores Neuromusculares

  • Succinilcolina = despolarizante; NÃO reverte com neostigmina; hipercalemia, hipertermia maligna.
  • Rocurônio/atracúrio/vecurônio = não-despolarizante (competitivo); reverte com neostigmina (ou sugamadex).

AINEs / Opioides

  • AINE = inibe COX → ↓prostaglandina. Não-seletivo → úlcera. Coxibe → risco CV. Paracetamol → hepatotox.
  • AAS = inibe COX irreversível → antiagregante.
  • Opioide = agonista μ → analgesia. RAM: depressão respiratória, constipação, miose. Antídoto = naloxona.
  • Tramadol → convulsão / sd. serotoninérgica. Codeína → pró-fármaco (CYP2D6).

Antipsicóticos / Sono

Clorpromazina × Haloperidol: ambos típicos (bloqueio D2). Haloperidol = alta potência → + extrapiramidal. Clorpromazina = baixa potência → + sedação/hipotensão/anticolinérgico.
  • Atípicos (risperidona, olanzapina, quetiapina, clozapina) = D2 + 5-HT2A → menos extrapiramidal, + síndrome metabólica. Clozapina → agranulocitose.
  • Benzodiazepínico = ↑frequência de abertura do Cl⁻ no GABA-A. Antídoto = flumazenil. Barbitúrico = ↑duração.
  • Insônia: zolpidem (Z) / trazodona + higiene do sono.

Parkinson / Neurodegener.

Levodopa + carbidopa: dopamina não passa a BHE → dá levodopa (precursor). Carbidopa = inibe DOPA-descarboxilase periférica → + levodopa no SNC, menos RAM periférica.
  • Entacapona (COMT), selegilina (MAO-B), pramipexol (agonista D2), biperideno (anticolinérgico).
  • Alzheimer: donepezila/rivastigmina (↑ACh) + memantina (antagonista NMDA).

Digoxina / Antiarrítm. / Vasoativos

Digoxina + furosemida: furosemida → hipocalemia → K⁺ e digoxina competem na Na/K-ATPase → hipoK potencializa toxicidade da digoxina → arritmia. Sinais: náusea, xantopsia, arritmia.
  • Digoxina MA = inibe Na/K-ATPase → ↑Ca intracel → ↑contratilidade.
  • Antiarrítmicos: I-Na, II-βbloq, III-K (amiodarona: tireoide/pulmão/fígado), IV-Ca.
  • Nitrato → NO → ↓pré-carga (angina); cefaleia, tolerância.
  • Adrenalina dose: baixa = β (vasodilata/↑FC), alta = α (vasoconstrição/↑PA).

Dislipidemias

  • Estatina (atorva/rosuva) = inibe HMG-CoA redutase → ↓LDL; RAM miopatia, ↑TGO/TGP.
  • Fibrato (fenofibrato) = PPAR-α → ↑lipase lipoproteica → ↓TG (hipertrigliceridemia isolada). Interação: + estatina = rabdomiólise; + varfarina = sangramento.
  • Ezetimiba (↓absorção colesterol), niacina (flush), colestiramina (resina).

Coagulação

"Anticoagulante enteral" = varfarina: inibe epóxido-redutase da vit K → ↓fatores II, VII, IX, X (K-dep). Monitor INR, antídoto vit K, efeito lento (age na síntese).
  • Heparina = ativa antitrombina (IIa+Xa); TTPa; antídoto protamina; HIT. HBPM = + Xa.
  • DOAC: rivaroxabana/apixabana (Xa), dabigatrana (IIa).
  • Antiagregante: AAS (COX/TXA2), clopidogrel (P2Y12). Fibrinolítico: alteplase, estreptoquinase.

Véspera: leia isto + escreva de cabeça os 12 fármacos-chave (classe/MA/RAM). Não estude assunto novo no dia da prova.
