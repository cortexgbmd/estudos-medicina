# StudyGen — Processos Neoplásicos (Anatomia Patológica)

Material de estudo interativo gerado a partir das aulas de Anatomia Patológica sobre Neoplasias
(3 aulas, 72 slides). Site único com 3 abas: **Estudo Completo**, **Questões** (30 objetivas +
8 dissertativas + 24 flashcards, com modo simulado e painel diagnóstico) e **Resumão pré-prova**.

> Conteúdo derivado exclusivamente das transcrições + slides da disciplina (sem pesquisa externa).
> Acesse: abra o `index.html` (publicado via GitHub Pages).
